# Writeback suggestions

This directory holds extracted claims and insights generated by CocoIndex-derived memory flows. No file in this directory is canonical Wiki content.

## Workflow

1. A CocoIndex pipeline extracts claims from validated Wiki pages.
2. Each claim is written here as a YAML file with structured fields.
3. A human reviews each suggestion for accuracy and relevance.
4. Approved suggestions are promoted into `wiki/` via normal Wiki workflow (edit, `wiki fmt`, `wiki check`).

## Claim format

```yaml
source_page: Agent_Memory.md
source_heading: Agent memory
source_fragment: agent-memory
confidence: 0.85
claim: |
  CocoIndex materializes derived memory that is disposable and rebuildable.
  Generated claims must be reviewed before becoming canonical.
extracted_at: "2026-07-21T00:00:00Z"
reviewed: false
```

## Rules

- Never auto-promote suggestions into `wiki/`.
- Every suggestion must preserve `source_page`, `source_heading`, and `source_fragment` for provenance.
- Set `reviewed: true` and add a `reviewer_note` after manual review.
- Delete rejected suggestions rather than leaving them stale.
